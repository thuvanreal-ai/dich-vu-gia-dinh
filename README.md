# Dịch Vụ Gia Đình — V1

Static website MVP cho giai đoạn test marketing tại TP.HCM.

## Mục tiêu
- Landing page chuyển đổi nhanh
- Dịch vụ trọng tâm: thông nghẹt + sửa nước nhẹ
- CTA gọi điện / Zalo
- SEO cơ bản
- Tracking hooks cho GA4/GTM

## Cần thay trước khi chạy quảng cáo
- 0900000000 bằng số vận hành thật
- https://example.com bằng domain thật
- Thêm GA4/GTM chính thức
- Thêm hình ảnh/case thực tế

## Tracking events
- click_call
- click_zalo
